## 先说清楚：IPLC VPS 和普通香港 VPS 差在哪

IPLC（International Private Leased Circuit，国际私有租用线路）本质是一条点对点的专用电路。按照公开的电信定义，租用线路是两端永久连接、独占使用的私有通信线路，由于不承载第三方流量，运营商可以对质量做出明确承诺（参考 Wikipedia 对 Leased Line / IPLC 的定义）。

落到实际使用上，这意味着两件事：

- **延迟可预期**。你的流量从国内入口直接进专线，到香港出口再上公网，绕开了拥堵的公网国际出口。Mkcloud 官网公示的广港线路端内延迟是 1~2ms，沪港线路 21ms，沪日线路 25~28ms。
- **晚高峰不挤**。专线带宽是你买的这段就是你的这段，不像公网线路在峰值时段大家抢同一根管道。

代价也很直白：贵。普通香港VPS每月几十块，IPLC VPS 起步就是几百元人民币一个月。所以这类产品从来不面向所有用户，它服务的是“网络质量直接换算成钱”的场景——跨境ERP同步、海外广告投放管理、金融行情接口、对延迟敏感的远程办公，这类需求才回得了本。

顺带说一句 IPLC 和 IEPL 的区别，很多人分不清：IPLC 是传统点对点电路，IEPL 是以太网版的专线，对用户来说核心差别不大，都是“独享、点对点、不过公网”。Mkcloud 的广东—香港线用的是 IEPL，上海出发的几条线标注为 IPLC，实际体验层面都属于同一类产品。

## 沪港、沪日、沪美：按目标地区和延迟挑

## 买之前必须知道的五条规则

这部分比价格更重要，都是官网购物流程里白纸黑字写明的限制：

1. **实名 + 省级白名单**。购买需中国身份实名。所有标准专线产品采用省级白名单措施——开通时选定一个省份，之后只有该省的IP能连入（省份可以随时修改）。官方说明这是为了排除机场、回国等违规用途。如果你的使用地点会频繁跨省，这点要想清楚。
2. **用途限制**。仅限个人或企业正规用途，明确禁止机场、回国等违法违规用途，违规一经发现立刻清退不退款。
3. **退款政策**。仅支持质量问题退款，而且要你提供具体到延迟数据、速度数据的证据；服务开通后不支持更换到其他地域的产品。下单前把线路选对，没有反悔药。
4. **支付方式**。目前只支持支付宝。
5. **系统安装**。云服务器开通后需要自己去控制面板装系统，Ubuntu、Debian、CentOS、AlmaLinux 等主流发行版都有，版本从 Ubuntu 14.04 到 24.04 都能选。
